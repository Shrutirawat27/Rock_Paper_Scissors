# Rock Paper Scissors Game
A simple and interactive Rock-Paper-Scissors game built using HTML, CSS, and JavaScript. The user plays against the computer, and the game instantly displays results and updates scores.

## Live Demo
https://rock-paper-scissors-beta-ruby.vercel.app/

## Features
- Play Rock, Paper, or Scissors against the computer  
- Random computer selection  
- Win, Lose, Draw results  
- Score tracking  
- Responsive and clean UI

## How to Use
1. Open the game in your browser  
2. Choose Rock, Paper, or Scissors  
3. Computer auto-selects a move  
4. View the result and updated score
